# Дипломная работа. Часть 2. Задание 2. Автотесты API
Проект тестирования эндпоинтов API [Stellar Burger](https://stellarburgers.education-services.ru/)

## Технологии
- IntelliJ IDEA 2025.2.4
- JDK corretto-11.0.28
- Build System Maven 3.9.11
- JUnit 4.13.2
- Allure 2.15.0
- RestAssured 5.5.5

## Параметры проекта и постоянные тестовые данные
Файл [resource.properties](src/test/java/config/resource.properties)

## Тестовые сценарии
1. **Создание пользователя:**
    - создать уникального пользователя;
    - создать пользователя, который уже зарегистрирован;
    - создать пользователя и не заполнить одно из обязательных полей.
2. **Логин пользователя:**
    - вход под существующим пользователем;
    - вход с неверным логином и паролем.
3. **Создание заказа:**
    - с авторизацией;
    - без авторизации;
    - с ингредиентами;
    - без ингредиентов;
    - с неверным хешем ингредиентов.

## Запуск тестов
```
mvn clean test
```
